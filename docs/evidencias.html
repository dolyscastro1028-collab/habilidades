1. Diagrama relacional de la base de datos

La base de datos habilidades tiene 10 tablas propias del sistema, relacionadas con llaves foráneas. PK = llave primaria, FK = llave foránea, UK = valor único.

    profesores ||--o{ cursos : "dicta"

    cursos ||--o{ modulos : "contiene"

    roles {
        bigint id PK
        varchar nombre UK "admin, profesor, estudiante"
    }
    users {
        bigint id PK
        varchar name
        varchar email UK
        varchar password
        bigint role_id FK
    }
    estudiantes {
        bigint id PK
        bigint user_id FK,UK
        varchar identificacion UK
        tinyint edad
    }
    profesores {
        bigint id PK
        bigint user_id FK,UK
        varchar identificacion UK
        tinyint edad
        varchar materia
    }
    tematicas {
        bigint id PK
        varchar nombre UK
    }
    cursos {
        bigint id PK
        varchar nombre
        varchar duracion
        text descripcion
        bigint tematica_id FK
        varchar portada
        boolean publicado "borrador o publicado"
        bigint profesor_id FK
    }
    modulos {
        bigint id PK
        bigint curso_id FK
        varchar titulo
        int orden
    }
    lecciones {
        bigint id PK
        bigint modulo_id FK
        varchar titulo
        longtext contenido
        varchar video_url
        varchar video_archivo
        int orden
    }
    clases {
        bigint id PK
        bigint curso_id FK
        bigint estudiante_id FK
        timestamp created_at "fecha de inscripción"
    }
    progreso {
        bigint id PK
        bigint estudiante_id FK
        bigint leccion_id FK
        timestamp created_at "fecha en que la completó"
    }

Normalización

Forma normalCómo se cumple
1FNCada columna guarda un solo valor. Los módulos, lecciones, inscripciones y avances van en tablas propias, no en listas dentro de una columna.
2FNLas tablas intermedias clases y progreso solo guardan las llaves de la relación y su fecha; no repiten datos del curso, del estudiante ni de la lección.
3FNEl nombre, el correo y la contraseña están solo en users. estudiantes y profesores los consultan por user_id. El rol está en roles (role_id) y la temática en tematicas (tematica_id): cada nombre se escribe una sola vez.

Reglas de integridad

ReglaEfecto
UNIQUE (curso_id, estudiante_id) en clasesUn estudiante no se puede inscribir dos veces en el mismo curso.
UNIQUE (estudiante_id, leccion_id) en progresoUna lección solo cuenta una vez como completada.
ON DELETE CASCADE en módulos, lecciones, clases y progresoAl borrar un curso se borran sus módulos, lecciones, inscripciones y avances.
ON DELETE RESTRICT en users.role_id y cursos.tematica_idNo se puede borrar un rol que tenga usuarios ni una temática que tenga cursos.

El avance se calcula así: lecciones completadas del curso ÷ total de lecciones del curso × 100. El script con la estructura y los datos de prueba está en database/habilidades.sql.

4. Capturas de pantalla

Página de inicio. Presenta la plataforma, los cursos destacados y los accesos por rol.

Registro de estudiante. Nombre, identificación, edad, correo y contraseña.

Escritorio del administrador. Resumen de la plataforma, gráficas de inscritos y de actividad, y cursos más populares.

Cursos (administrador). Listado con estado (publicado o borrador), temática, profesor, módulos y lecciones, y los botones para publicar o pasar a borrador.

Editar curso. Datos del curso y sus módulos; cada módulo contiene sus lecciones con video.

Progreso de los inscritos. Lecciones completadas y porcentaje de avance de cada estudiante.

Temáticas. El administrador gestiona las temáticas; las que tienen cursos no se pueden borrar.

Crear estudiante (administrador). Incluye la cuenta de acceso para iniciar sesión.

Escritorio del profesor. Resumen y gráficas solo de sus cursos y sus estudiantes.

Mis cursos (profesor). El profesor solo ve y gestiona sus propios cursos, y decide cuándo publicarlos.

Editar curso (profesor). Temática, descripción, portada, y los módulos con sus lecciones.

Progreso de sus estudiantes (profesor). Avance de cada inscrito en el curso.

Escritorio del estudiante. Sus cursos con barra de avance y botón para continuar.

Catálogo de cursos. Tarjetas con temática, profesor, descripción, módulos, lecciones y duración. Se puede buscar y filtrar por temática.

Vista previa del curso. Antes de inscribirse, el estudiante ve la descripción y el temario con las lecciones bloqueadas.

Vista del curso. Módulos y lecciones, con las completadas marcadas.

Lección. Video, botón de completar, navegación y temario con el avance del curso.

Mi perfil. Cada usuario puede cambiar su nombre, correo y contraseña.
